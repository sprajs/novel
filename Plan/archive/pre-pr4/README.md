## Scope and limitations

These documents propose experiments; they do not report new experimental results or establish scientific discovery. Numerical budgets, thresholds, memory estimates, and configuration choices are planning assumptions. Literature results have not been independently reproduced. The plan preserves source links, source-access limitations, dataset licensing cautions, and unresolved historical eligibility questions.

Implementation still requires measured memory/runtime, immutable checkpoint and software revisions, empirically calibrated tasks, a powered sample-size decision, and audited historical cases if that branch is pursued. Any future compute rental requires its own provider and budget decision. No dependencies, models, or experiments are included in this repository.
