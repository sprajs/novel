# First working session: make hidden-context transfer measurable

The deliverable is the HC-1 generator and reference-policy packet described in
[the protocol](hidden-context-protocol.md). This is planned implementation work;
the repository does not yet contain that runner or experimental results.

| Work | Reviewable output | Stop condition |
| --- | --- | --- |
| Translate HC-1 A into observed events and evaluator records | Schema, event renderer and one hand-worked change/stay pair | Hidden labels enter model input or a query lacks necessary mapping evidence |
| Enumerate/group maps and split them | Frozen grouping/seed manifest; counts and no overlap | Counterfactual or action-complement twins cross partitions |
| Implement reference strategies | Per-item, feedback-gated reversal and exact observer scores | Analytical expectations or no-feedback chance fail |
| Specify ambiguity twins | Identical prefixes with opposite targets; second cue distinguishes them | Condition labels, serialization or timing reveal the hidden cause |
| Audit training and measurement interfaces | Input/output/state-reset specification, hashes and future-target-invariance check | Feedback precedes the decision it is meant to evaluate |
| Cost a bounded development run | Recipe and timing plan using the pinned CPU environment | Unsupported backend, unacceptable cost or numerical instability |

Do not start neural training until the generator/reference checks pass. Do not
open confirmation outcomes while choosing recipes. The first report can be a
measurement failure or a competence floor; neither is evidence that all neural
networks lack the target ability.

After the packet works, implement the proposed GRU and causal-transformer lanes
with matched experience and explicit costs. Follow the fixed development caps
and freeze decisions in HC-1. The pretrained-language-model lane, representation
capture and intervention studies have separate validation requirements.

For later scientific corpus work, use the [historical-corpus session](historical-corpus-session.md)
and retain its independent admission requirements.
