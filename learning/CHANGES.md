# Curriculum changes

## 12 October 2026 — first living baseline

Add a teaching path from model/probability foundations to corpus admission,
semantic measurement, adjudication and fixed-budget sampling. Keep causal
interventions, transfer and latent search behind the current study's evidence
gates. Summarize both existing reading inventories without promoting paper
claims to reproduced results. Add original diagrams, interactive examples,
a glossary and per-source access scope. Incorporate the owner's preference for
open reading: replace self-checks with fully explained examples and remove
completion checkboxes and progress tracking. Readers choose their own order.

Introduce a reviewed source fingerprint and repository check, a stable private
Site identity and a daily chat review. Future removals must record the reason
here; a retired source may remain as an audit record while disappearing from the
default active library and learning path.
